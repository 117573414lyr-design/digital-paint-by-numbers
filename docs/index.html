第一规则

网站与 Windows 生产软件共用验收标准。

  • 效果图尽量贴近原图，不为线稿方便粗暴简化。
  • 色块边界平滑，无白缝、透明缝、漏底、错位。
  • 每个色块闭合且唯一归属颜色编号。
  • 不可容纳约 5pt 编号的小碎块进入合并候选。
  • 线宽固定目标 0.1 pt。
  • 线色 CMYK 40,100,100,100。
  • 数字字号 4.2 / 6 / 8 pt。
  • 共享边界只保留一条，禁止双线、交叉、重叠、残线。
  • 效果图、线稿、配色图使用同一 region_id / color_id。
  • 数字必须在对应封闭区域内部，不越界、不压线。
  • 正式配色必须映射项目自有色库。
  • SVG/PDF 必须保留真实矢量对象。
