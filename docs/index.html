数字油画第一规则

效果图、编号线稿、配色图使用同一套区域和颜色关系。

  • 效果图尽量贴近原图，不为方便线稿而粗暴简化。
  • 相邻色块无白缝、透明缝、漏底和错位。
  • 每个色块必须闭合，并唯一归属一个颜色编号。
  • 无意义小碎块自动合并，但不能破坏主体结构。
  • 无法容纳约 5pt 编号的小区域进入合并/优化候选。
  • 线稿目标线宽固定为 0.1 pt。
  • 线稿目标颜色为 CMYK 40,100,100,100。
  • 编号字号采用 4.2 / 6 / 8 pt 三档。
  • 共享边界只保留一条，禁止双线、重叠线和交叉残线。
  • 编号必须落在对应区域内部，尽量远离边界。
  • 正式配色必须映射项目自有色库正式色号。
  • SVG / PDF 输出必须保留矢量线、色块或文字对象，不用整页栅格冒充矢量。
