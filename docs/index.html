数字油画第一规则

网站与 Windows 本地软件共用的生产验收标准。

  • 颜色尽量贴近原图，不为方便线稿而粗暴简化。
  • 色块边界平滑，无明显锯齿、白缝、透明缝、漏底和错位。
  • 每个区域必须闭合，并唯一归属于一个颜色编号。
  • 过小且无意义的碎块智能合并，不能破坏主体结构。
  • 无法容纳约 5pt 编号的小区域进入合并/优化候选。
  • 线宽固定目标 0.1 pt。
  • 线稿颜色目标 CMYK 40,100,100,100。
  • 编号字号目标 4.2 / 6 / 8 pt。
  • 相邻色块共享同一条边界，禁止双线、交叉线、重叠线和残留碎线。
  • 线稿区域轮廓、数量、相邻关系和边界必须与效果图严格对应。
  • 数字必须位于对应封闭区域内部，不越界、不压线。
  • 配色图必须使用项目自有色库正式编号，不使用临时聚类编号。
  • 效果图、线稿图、配色图共用同一套 region_id / color_id。
  • PDF/SVG 必须保留真实矢量路径和独立编号对象，不以整页栅格图冒充矢量。
