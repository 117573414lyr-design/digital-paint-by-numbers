# 数字油画生产设计中心 · Web V101

## 入口

- 页面文件：`docs/index.html`
- 目标：把数字油画项目近期确认规则与 `AGENTS.md` 的桌面生产规范统一到一个可直接运行的 Web 工作台。

## V101 已实现

- JPG/PNG 原图导入、拖放与预览
- 12 / 24 / 36 / 50 色目标选择
- 浏览器端轻量分色效果图
- 连通区域分析与区域统计
- 根据同一 `colorIndex` 生成边界，减少效果图/线稿错位
- 编号线稿预览，按区域中心自动放置正式色号/临时编号
- 小区域编号容量阈值检查
- 自有色库 CSV 导入：`color_id,r,g,b`，并执行最近 RGB 色映射
- 配色图/色卡预览
- 色卡 CSV 导出
- PNG 导出
- 项目 JSON 保存与恢复（包含参数、自有色库和原图预览）
- 自动 QC：PASS/WARN/FAIL 分级及定位说明
- 第一规则展示
- 学习中心：`reference_samples` / `negative_samples` / `corrections` / `parameter_profiles`
- 响应式桌面/移动界面

## 固定生产参数

- 线稿目标：0.1 pt
- 线色目标：CMYK 40,100,100,100
- 编号字号：4.2 / 6 / 8 pt
- 效果图、线稿图、配色图共用 `region_id / color_id`
- 相邻色块共享唯一边界；禁止白缝、双线、交叉线、未闭合区域
- 无法容纳约 5pt 编号的小色块进入合并/优化候选

## 自有色库 CSV

推荐格式：

```csv
color_id,r,g,b
A001,213,189,160
A002,122,91,71
A003,55,42,38
```

导入后，Web 分色结果会映射到自有色库正式色号。生产版本后续升级为 Lab / ΔE 色差匹配。

## Web 与桌面核心边界

Web V101 已可以完成快速分色、区域识别、编号预览、色库映射、项目保存和 QC 预检。

以下项目仍必须由生产级桌面核心完成：

- 真正的共享边界矢量拓扑
- 0.1 pt 精确矢量线宽
- 曲线/锚点生产级平滑
- 碎块拓扑合并与闭合修复
- Lab / ΔE 自有色库精确匹配
- 可编辑 SVG / PDF / AI
- PDF 中独立可编辑文字编号
- 完整生产 QC

禁止将整页栅格图包装成“矢量 PDF”。
