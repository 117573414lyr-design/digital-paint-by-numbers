# 数字油画生产设计中心 · Web V103

## V103 新增

- 自有色库匹配从 Lab / ΔE76 升级为 Lab / ΔE2000。
- 继续保留小碎块自动合并、连通区域分析与同源 `colorIndex`。
- 新增边界简化档位，为后续 Bézier / 锚点优化提供参数入口。
- 编号位置改为区域内部安全点策略，不直接机械使用几何中心。
- 编号容量与越界风险 QC 分开检查。
- SVG 继续输出真实 `path + text` 矢量对象，并写入 `0.1pt` 生产线宽。
- 三页 PDF 生产包结构升级为：效果图 / 编号线稿 / 配色图，并携带矢量线宽、文字对象和 ΔE2000 元数据。
- 色卡 CSV 同步输出 RGB + Lab。

## 固定生产参数

- 线稿目标：`0.1 pt`
- 线色目标：`CMYK 40,100,100,100`
- 编号字号：`4.2 / 6 / 8 pt`
- 效果图、线稿图、配色图共享 `region_id / color_id`
- 相邻区域共享唯一边界
- 小碎块优先合并，不保留无法稳定编号的无意义区域
- 数字不得越界、压线或进入错误区域
