# 数字油画生产设计中心 · Web V104

## V104 新增

- 自有色库继续使用 Lab / ΔE2000 精确匹配。
- 小碎块自动合并改为统计区域真实共享边界后选择合并目标。
- 编号位置升级为“最大内距近似”搜索：在色块内部寻找距离边界更远的位置，而不是直接使用几何中心。
- 编号安全距离纳入 QC，可识别贴线/越界风险。
- 共享边界支持精细 / 标准 / 强简化三档步长。
- SVG 继续输出真实 `path + text` 矢量对象，线宽写入 `0.1pt`。
- **三页 PDF 现在由浏览器直接生成真正的 PDF 文件，不再只是 JSON 结构包。**
  1. 第 1 页：效果图，使用矢量填充矩形色带生成。
  2. 第 2 页：编号线稿，使用 PDF 矢量线段 + 独立文字对象生成。
  3. 第 3 页：配色图，使用矢量色块 + 独立文字对象生成。
- PDF 使用 Helvetica 基础字体对象，线稿写入 `0.1` pt 矢量线宽。
- 效果图、线稿、配色图仍共享同一套 `colorIndex / color_id`。

## 固定生产参数

- 线稿目标：`0.1 pt`
- 线色目标：`CMYK 40,100,100,100`
- 编号字号：`4.2 / 6 / 8 pt`
- 色差：`Lab / ΔE2000`
- 相邻区域共享唯一边界
- 无法稳定放号的小碎块优先合并
- 数字不得越界、压线或进入错误色块

## 仍需桌面生产核心继续完成

Web V104 已经能生成真正的三页 PDF 矢量对象，但最终 Illustrator 级生产质量仍需要桌面核心继续加强：

- Bézier 曲线拟合与更自然的圆滑边界
- Douglas-Peucker / 曲率感知锚点精简
- 真正共享的曲线拓扑对象，而不是相邻像素边界抽样
- 复杂孔洞、嵌套区域、岛状区域修复
- 更严格的 polylabel / 最大内接圆算法
- CMYK 色彩管理与印前 PDF 参数
- Illustrator / AI 原生兼容结构
- 字体嵌入与中文/特殊色号支持
- 最终生产 QC 与可编辑图层结构
