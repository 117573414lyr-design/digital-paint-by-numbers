# 数字油画生产设计中心 · Web V102

## 入口

- 页面：`docs/index.html`
- 目标：把近期数字油画“第一规则”和 `AGENTS.md` 生产规范统一进一个可直接运行的 Web 工作台。

## V102 新增

- Lab / ΔE76 色差计算与自有色库匹配
- 小碎块自动合并：优先并入共享边界最多的相邻色块
- 重新构建效果图与连通区域统计
- 编号容量与越界风险预检
- 编号线稿：边界与编号都由同一 `colorIndex` 派生
- 真 SVG 导出：`path` 边界 + 独立 `text` 编号对象
- SVG 线宽按 `0.1pt` 写入
- 项目 JSON 保存与恢复
- 项目文件写入 PDF 三页结构元数据：`effect / linework / palette`
- 色卡 CSV 导出，包含 RGB / HEX / Lab
- QC 对碎块、编号、安全区域、色库、SVG 矢量结构等进行 PASS/WARN 检查

## 已有能力

- JPG/PNG 原图导入、拖放与预览
- 12 / 24 / 36 / 50 色目标选择
- 浏览器分色效果图
- 连通区域分析与区域统计
- 自有色库 CSV 导入
- 配色图 / 色卡预览
- PNG 导出
- 第一规则展示
- 学习中心数据结构
- 响应式桌面/移动界面

## 固定生产参数

- 线稿目标：`0.1 pt`
- 线色目标：`CMYK 40,100,100,100`
- 编号字号：`4.2 / 6 / 8 pt`
- 效果图、线稿图、配色图共用 `region_id / color_id`
- 相邻色块共享唯一边界
- 禁止白缝、双线、交叉线、未闭合区域
- 无法容纳约 5pt 编号的小色块进入合并/优化候选

## 自有色库 CSV

推荐格式：

```csv
color_id,r,g,b
A001,213,189,160
A002,122,91,71
A003,55,42,38
```

V102 会把 RGB 转为 Lab，并通过 ΔE76 将分色结果映射到自有色库正式色号。

## Web V102 与桌面生产核心边界

Web V102 可以真实输出 SVG 边界路径和独立文字对象，但仍属于浏览器快速生产预览层。最终生产版仍应由桌面核心完成：

- 曲线级共享边界拓扑优化
- 生产级 Bézier 平滑与锚点精简
- 复杂碎块拓扑修复
- 更严格的编号内接区域 / polylabel 放置
- ΔE2000 等更高精度色差策略
- 三页可编辑矢量 PDF 实际生成
- AI / Illustrator 兼容输出
- 最终生产 QC

禁止将整页栅格图包装成“矢量 PDF”。

## PDF 三页结构

项目 JSON 已预留：

1. `effect`：数字油画效果图
2. `linework`：编号线稿
3. `palette`：配色图 / 色卡

三页必须共享同一套颜色 ID 和区域 ID。
